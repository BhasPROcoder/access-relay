# Four-minute demo outline

1. **0:00–0:30:** Team and problem: a usable entrance alone does not establish a usable service visit. Identify all data as fictional.
2. **0:30–1:15:** Compare three journeys: barrier, stale observation and current observations. Explain no safety guarantee.
3. **1:15–2:15:** Staff claims the library ramp repair. Status remains pending. The same actor cannot recheck.
4. **2:15–3:00:** Reviewer fails or passes the claim. The unobserved library desk still prevents a complete current journey.
5. **3:00–3:30:** Show keyboard navigation, timestamps, print view and automated tests. Demonstrate offline mode only if actually verified.
6. **3:30–4:00:** Explain local-only persistence, simulated identity, established alternatives, AI assistance and the proposed beneficiary/staff validation.

Do not invent user counts, prevented incidents, partnerships or audited compliance. Show real test output and describe what it does and does not verify.
